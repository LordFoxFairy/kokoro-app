# 技能：安装、版本与发布管理

本页区分当前可用能力和待完成能力。页面存在、接口返回 200、版本发布和安装生效是不同事实；读取或预览不执行技能。

## 发布确认与历史恢复

正常 App/BFF/Platform/Admin 已配对发布确认契约：已有系列先读取真实当前指针和版本，确认后冻结原请求及幂等键；未知结果保留原意图，冲突需要显式重新开始，不自动覆盖其他更新或升级安装。新系列明确无 publication，读取失败不当作从未发布。

本人系列历史和精确版本预览已正常实测；历史恢复已接入既有新版本发布链并通过正常原包整链验收；永久删除、公开身份矩阵及后台剩余负控/草稿丢弃仍待完成。恢复必须取原始 ZIP 并生成新 UID，不能拼接预览文字重建包，也不把管理员解除隔离当历史恢复。模型、工具执行与扣费暂停。

### 项目页的能力开关

项目技能入口由现有站点 runtime manifest 的 `workspace.skills`／`project.skills` 控制，不是执行权限。2026-10-21 正常项目页实测未展示该入口；同源清单返回200、configVersion为1，但仅有 `chat` 开关，现有组件据此保持关闭。运行与候选的能力投影代码相同，不是重启或恢复旧布局可以解决的问题。当前未修改该配置，正常项目列表并集及精确版本页面验收仍未完成；不通过前端常开兜底掩盖配对缺口。

详情读取该安装固定的精确版本及包文件。目录展示的当前发布版本不替换已安装版本；发现新版本后，通过明确的安装更新动作确认。阅读旧版本、更新发布内容不会自动改写旧消息引用或升级其他安装。

普通新建支持 ZIP／`.skill` 文档包与既有 GitHub 导入流程。上传、扫描、draft 校验或发布阶段的回执不单独证明已安装；以真实安装回执及刷新结果为准。输入错误可修改，结果未知时保留原意图，通过现有恢复入口核实，不重新创建另一份命令。

## 个人发布管理

已安装技能的管理入口先核验精确版本的正式发布者资格，再打开更新或撤回窗口。安装者不自动成为发布者；显示名称也不是权限证明。

- **更新发布内容**：使用新的包创建并发布不可变修订；不直接覆盖旧包，不自动升级现有安装。
- **撤回**：按 owner 当前规则使对应发布不可用于新的获取；不是永久删除。历史安装引用与系列当前发布不一致时，仍需遵守精确目标和发布 CAS，不能静默改成操作最新版本。
- **安装移除**：与发布撤回分开，不能据此宣称源技能和版本已删除。

当前正常页面已支持本人系列历史与精确版本预览；历史恢复支持二次确认、原ZIP生成新UID、关闭重开保留同一次尝试，已加载正常页面；删除旅程仍未提供。不要把管理员隔离状态恢复当作用户版本恢复，也不要把撤回按钮改名为删除。

## 内部维护与接口边界

- **App**：设置使用 `SkillsSettingsSection → SkillsContent`；正式 client 从 installation 集合读取精确版本。`PersonalSkillsRead` 无生产调用，不据其按页选择最大 revision 的代码修改正式版本规则。
- **BFF**：拥有 Product 聚合及对象授权，页面同源 adapter 只进入其固定契约；网站私有展示接口和公开 `/v1/skill.list` 分开治理。
- **Platform**：拥有源技能、不可变版本、包校验、发布、安装与生命周期事实。读取列表不增加执行权。
- **IAM**：拥有可信主体与当前资格。公开 API Key、普通 Open App OAuth、trusted client 的完整 producer／对象范围仍有缺口；八类 `owner_type` enum 存在不证明身份链已实现。
- **Admin**：沿原 Skills 管理面消费既有操作；核心创建、上传扫描、发布、新版本、可见范围、隔离/显式恢复、撤回及用户目录投影已正常自验；草稿丢弃的真实浏览器动作、失败恢复和权限矩阵仍须对应证据，不用一次读取替代。

页面读取包括同源 `GET /api/hub/self/skill-installations`、精确安装详情及发布者核验的 `GET /api/hub/self/skills/managed/{skill_id}`。其 wire 由固定 BFF artifact 管理，不在本页复制可编辑 DTO 或另立 OpenAPI。完整能力状态见[当前记录](../CURRENT.md)，组件职责见[Skills 索引](../../src/ui/skills/INDEX.md)。
