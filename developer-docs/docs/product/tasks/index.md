# 任务与对话

从明确发送开始，查看实际执行状态、回复并在原会话继续工作。需要资料时先读[附件与文件](../files/index.md)。

## 发送与查看过程

1. 确认正文和已选资料，再发送。
2. 查看排队、执行中的状态和实际回复。复杂任务可能有 Todo、工具、子 Agent 或需要你决定的事项；简单问答不强制显示一份计划。
3. 展开过程详情可以了解已发生的操作，但过程展开状态不是执行成功证明。
4. 需要中止时使用停止；界面确认最终停止前，仍可能处于停止中。

输入框里的新草稿不等于已经提交。审批、补充回答、停止和普通新消息是不同操作，不用连续点击发送来处理不确定结果。

## 模型和工具准备

输入框保留一个任务入口，按需选择模型、Skills 和连接器；选择资料或工具不会自动发送。没有可用模型目录时会显示加载或读取失败，失败后可使用原位置的重试操作，草稿保持不变。已有确认的模型选项不会因暂时读取失败被清空。

连接器菜单在原列表显示加载、失败或真实空态。失败不等于没有连接；可以关闭后重新打开刷新，或进入现有管理入口核对。连接器是否可用、任务是否成功，以实际状态和结果为准。

任务结束后，未得到独立完成结果的 Skill 显示中性结束状态，不冒充加载成功。模型调用未获准时同时检查可用积分和模型权限；已生成的正文与结果仍保留。

## 断线和刷新

同一会话会从已保存的消息、事件和结果恢复。切回原会话或刷新后，应先看当前状态，再决定是否需要新操作。

原页面可能保存未发送草稿和资料选择；切换账号、租户或不同会话不应把别人的草稿带过来。网络错误、明确失败、仍在执行与提交结果未知不同；不要把重连当成新执行，也不要在未知结果时反复创建同一任务。
