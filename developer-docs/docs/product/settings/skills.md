# 技能草稿

在 **设置 → 技能 → 添加 → 草稿** 中管理自己的未发布草稿。草稿修改不会发布技能、更新已安装版本或启动 Agent。

## 编辑已有草稿

1. 打开草稿列表，找到目标并选择 **编辑草稿**。页面会重新读取当前草稿，而不是直接使用列表中的旧内容。
2. 修改名称、简介、标签、示例提示或类别。示例支持多行；每个标签和示例分别编辑，原有顺序保持。
3. 选择 **保存修改**。看到“草稿已保存并重新读取”后，当前表单显示的是服务器重新返回的内容。
4. 关闭后可以再次打开；刷新页面后从草稿列表重新选择，读取已保存内容。未保存的表单不承诺跨刷新保留。

## 保存遇到问题

- **结果未知**：使用“重试原保存命令”，不要假定第一次没有保存。恢复保留原内容与命令身份，不自动覆盖其它修改。
- **已确认保存但读取失败**：重新读取当前草稿即可，不会再次提交保存。
- **草稿已变化**：先检查提示，再明确重新载入当前草稿；不会自动把旧编辑覆盖到新版本。
- 关闭窗口或取消编辑不新增保存请求。账号或租户切换后，旧窗口不继续操作。

本入口仅编辑 metadata；封面、丢弃草稿、AI 创建与 ZIP 发布不是本轮新增能力。已发布技能仍沿原有版本管理流程。
