# 个性化与个人知识

在工作台打开 **设置 → 个性化**，可以填写个人资料、回复偏好，以及自己维护的知识。这些内容属于你的个人设置；它们不是项目指令，也不会因打开设置而发送消息或启动任务。

## 编辑个人资料

1. 选择 **个人资料** 标签。
2. 按需要填写 **昵称**、**职业**、**更多关于你的信息** 和 **自定义指令**。例如，可以说明希望回复简洁，或约定常用的输出格式。
3. 编辑后点击其他字段或移开输入焦点，页面会自动提交保存。等待 **已保存** 提示，再继续发送需要使用这些设置的新消息。

个人资料没有单独的常规保存按钮。各字段显示字符数和上限；超限输入会显示提示，不会替换原内容。

如果页面提示保存结果尚未确认，先选择 **重新读取**。页面会保留草稿，并展示当前保存的资料，供你选择 **采用服务器资料**，或 **在新版本上保存我的草稿**。不要把仍在输入框里的草稿当成已经保存的内容。

## 维护个人知识

1. 在同一页面切换到 **知识** 标签，点击 **新增**。
2. 填写 **名称**、**使用时机** 和 **内容**，再点击 **保存**。例如，为常用的报告格式添加一条知识，并说明希望何时使用。
3. 通过搜索查找已有知识；点击对应条目的编辑按钮，可以修改后再次保存。
4. 不再需要的条目可点击删除按钮，再选择 **确认删除**。删除没有恢复入口，请先核对条目名称。

知识最多保存 100 条，每条内容最多 2000 个字符。编辑表单的 **取消** 或关闭按钮用于退出编辑，不等于保存。

如果出现保存结果未核实的提示，使用 **核实当前值** 查看实际保存结果；需要时再选择 **保留当前保存值**。页面不会自动重新提交未确认的操作。

### 开启或关闭使用知识

**使用知识** 开关控制后续新消息是否使用已保存的个人知识。关闭并确认保存后，条目仍保留在列表中，但不再加入后续新消息的个人上下文；重新开启后，后续新消息可再次使用这些条目。开关不删除知识，也不关闭个人资料和自定义指令。

加载或保存尚未确认时，相关操作可能暂时禁用。先处理页面提示并确认保存状态，不要将加载失败理解为知识已经清空。

## 哪些消息会使用修改后的内容

- **新发送的消息** 使用发送时已保存的个人资料，以及当时已开启使用的个人知识。保存设置本身不会发消息。
- **已经提交或正在执行的消息** 保持提交时的内容，不会在执行途中换成刚修改的设置。
- **重新生成旧消息** 沿用该消息最初使用的个人上下文。即使后来修改、关闭或删除知识，重新生成也不会自动换用当前设置；旧消息当时没有个人上下文时，重新生成也不会补入。

要使用最新设置，请确认保存成功后，主动发送一条新消息。设置用于提供背景和回复偏好，不保证每次回复都会逐条引用知识。

## 当前边界

个人知识是你手工添加和维护的内容，不是从所有对话中自动积累的长期记忆。当前也没有接通外部记忆导入：**导入记忆** 弹窗可复制提示、填写临时内容，但导入按钮尚未开放，关闭后不会保存为个人知识。
