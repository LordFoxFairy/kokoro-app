# 开始使用 Kokoro

Kokoro 把一次工作放在同一个会话里：描述目标、补充资料、查看执行过程、检查结果，再继续修改。项目用于整理相关会话和资料，定时任务用于按时间执行工作。

本指南对应 Task A 已交付的工作台。功能是否可见还取决于当前账号权限、模型和运行环境；不要把下文理解为所有外部服务已经部署或连接。

## 完成第一项任务

1. 登录后打开工作台首页 `/app`。
2. 在输入框写清目标、范围与结果形式。例如：“阅读我选择的两份文本，列出差异，并用 Markdown 总结。”
3. 需要资料时，打开输入框的 **＋**，选择本地文件、资料库或最近任务中的结果。确认选择后，仍需主动发送消息。
4. 发送后查看回复和实际执行过程。需要你的决定时，先阅读提问或审批内容，再回复或选择。
5. 检查最终答复及交付文件。继续修改可在原会话发送补充要求；刷新页面用于恢复原会话，不是重新提交一次任务。

## 先分清四个对象

| 对象 | 用来做什么 | 不是什么 |
| --- | --- | --- |
| 会话 | 保存连续消息和执行历史 | 不是一个只执行一次的任务 |
| 一次执行 | 处理一轮已发送消息 | 排队、运行、停止中不等于完成 |
| 项目 | 组织相关会话、指令、资料和手工 Todo | 不是独立执行引擎 |
| 定时任务 | 在指定时间或周期启动工作 | 不是项目里的手工 Todo |
