# 项目与定时任务

## 用项目组织长期工作

项目把相关会话、指令、资源和手工 Todo 放在一起。打开项目概览本身不会发送消息；需要开始工作时，在该项目内输入并主动发送。

1. 在侧栏创建或打开项目，填写清晰名称。
2. 按需要保存项目指令，描述目标、格式和工作约定。
3. 添加当前项目可以访问的资料，在发送前确认实际选择。
4. 在项目内创建会话，或用现有移动操作整理会话；移动不等于重新执行已有消息。

指令保存后用于后续新执行；已经开始的同一次执行恢复时不会悄悄换成另一版指令。项目网站列表只是显式保存的网址引用，不代表系统会自动抓取网页、创建网站或发布部署。

### 手工 Todo

项目 Todo 可创建、改名、删除，并在待办、进行中、完成之间切换。它是人工管理的项目清单；Agent 执行过程里的 Todo 与定时任务另有各自用途，改变项目 Todo 状态不会启动一个执行。

### 删除与可见性

删除前阅读确认内容。项目和会话有真实归属与访问权限；把会话放入项目、保留网址或收藏结果，都不是给其他人授权。团队、分享权限和连接管理使用各自已提供的正式入口，不由本指南推导额外访问权。

## 设置定时执行

打开 `/app/scheduled`，在任务列表或日历查看计划。

1. 创建任务，写清要执行的内容。
2. 选择一次性时间或周期，明确时区，再保存。涉及跨地区工作时，应确认页面中的时区，而不只看本机时钟。
3. 编辑后回读计划；需要暂时不再到点启动时使用暂停，需要继续时恢复。
4. 从 **Updates／执行记录** 查看实际结果，打开已有结果会话继续阅读。

项目筛选只帮助定位对应记录，不会替你创建任务或改变现有任务归属。保存成功仅表示计划已保存；到点被接纳也不等于执行成功，必须看最终状态和结果。

暂停或删除影响后续调度，不等于把已接纳执行的结果从历史中抹掉。若正在执行，按会话里提供的实际停止能力处理，不用反复暂停／恢复当作取消。

## 检查结果而不是只看提醒

查看计划时间、执行状态和结果链接。失败、取消、等待用户决定与完成应分别处理；没有真实结果的记录不伪装成一份已生成文档。

文档组织参考 [Manus Projects](https://manus.im/docs/features/projects) 和 [Automations](https://manus.im/docs/automations)，核对于 2026-11-11 UTC。Kokoro 此处说明的是已支持的定时任务；不据此承诺 Manus 的事件触发、协作权限或高级自动化功能。
