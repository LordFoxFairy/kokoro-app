# 连接与语音

连接状态、账号授权与浏览器能力不同，先确认适用条件，再按相应入口操作。

## 语音输入

支持的浏览器可以通过语音按钮请求麦克风权限，把识别结果加入可编辑草稿。先检查并编辑文本，再主动发送；识别完成不自动发出消息。

浏览器兼容性、麦克风权限及识别服务可用性会影响结果。当前方式使用浏览器原生语音识别，不是上传一份录音到 Kokoro 的通用转写接口。最终编辑并发送的体验仍需在实际目标浏览器核验，不承诺所有浏览器均已验证。

## 外部聊天连接

Telegram、LINE、Slack 的工作台设置入口位于 `/app/agents`。按实际向导完成设置和必要授权，核对连接状态；需要停用时使用正式断开操作。

- 服务端配置和你的外部账号授权是前提，卡片存在不代表已经连接。
- 本地协议及浏览器流程已验；真实外部账号授权、收发、撤销仍待各供应商环境验收。
- **设置 → 集成** 中的说明卡片不等于上述可用入口；禁用按钮不要当作已完成连接的证明。
- Skills、MCP、自定义 API、账户与团队管理有独立的正式入口和授权范围，分别确认是否可用。

连接概念参考 [Manus Connectors](https://manus.im/docs/integrations/connectors)，核对于 2026-11-11 UTC；没有照搬其目录、连接数量或能力承诺。
