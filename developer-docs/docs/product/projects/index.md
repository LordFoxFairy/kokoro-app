# 项目

## 用项目组织长期工作

项目把相关会话、指令、资源和手工 Todo 放在一起。打开项目概览本身不会发送消息；需要开始工作时，在该项目内输入并主动发送。

1. 在侧栏创建或打开项目，填写清晰名称。
2. 按需要保存项目指令，描述目标、格式和工作约定。
3. 添加当前项目可以访问的资料，在发送前确认实际选择。
4. 在项目内创建会话，或用现有移动操作整理会话；移动不等于重新执行已有消息。

指令保存后用于后续新执行；已经开始的同一次执行恢复时不会悄悄换成另一版指令。项目网站列表只是显式保存的网址引用，不代表系统会自动抓取网页、创建网站或发布部署。

### 手工 Todo

项目 Todo 可创建、改名、删除，并在待办、进行中、完成之间切换。它是人工管理的项目清单；Agent 执行过程里的 Todo 与定时任务另有各自用途，改变项目 Todo 状态不会启动一个执行。

## 与当前团队成员协作

项目所有者可在项目页顶部打开 **分享／Share**。这里的项目链接只定位项目，不会向拿到链接的人自动授予权限，也不是公开会话快照。

1. 选择当前团队中的成员；若成员目录读取失败，先重新读取，不用手填外部邮箱代替。
2. 选择 **只读／Viewer** 或 **编辑／Editor**，按需要填写到期时间；留空表示不设到期时间。
3. 点击 **保存授权／Save grant**。成员在自己的登录会话中打开该项目，刷新后确认当前角色和内容。
4. 修改角色时再次明确保存；结束共享时对该成员点击 **撤销访问／Revoke access**。

| 角色 | 允许的项目操作 |
| --- | --- |
| 所有者 | 管理项目内容、成员授权及项目删除 |
| 编辑成员 | 读取与编辑获准内容，创建项目会话和任务；不管理成员授权或删除项目 |
| 只读成员 | 阅读获准内容与结果；不修改项目或发起执行 |

保存后另一成员可编辑项目指令，所有者重新打开或刷新后读取同一份已保存内容。只读成员看到只读状态；到期或撤销后，后续读取和写入按当前权限重新判断。已下载到本地的文件不会因此自动收回。

授权结果未确认时，使用 **恢复原命令／Resume original command** 核对原操作，不反复改角色或新建授权。权限版本冲突时先刷新当前状态，再决定是否重新操作。

### 哪些内容不会随项目共享

同团队身份本身不开放个人项目或私人会话。共享范围限明确属于这个项目的会话、指令、任务、资源与安全结果；个人置顶仍是各自的偏好。

其他成员的私人思考、工具原始输入输出、过程文件、个人知识、连接凭据与资金明细不在共享范围。编辑成员发起工作时使用自己的模型、连接与执行资格，不因此取得控制他人 Run 的权限。正式交付结果与私人过程文件也不是同一种资料。

成员离开团队期间访问停止；同一账号重新加入后，仍有效的项目授权可能恢复。需要永久终止该项共享时，由所有者显式撤销授权。

### 删除与可见性

项目删除由所有者执行，删除前阅读确认内容；它会影响项目内不同成员创建的内容，不只是所有者自己的会话。移动会话按移动后的项目归属重新判断访问，既有执行身份和历史结果不被改写。

保留网址、收藏结果或复制项目链接都不是授权。公开会话快照仍是独立的只读分享入口，不提供继续聊天、执行控制或项目成员资格。实际环境的验收范围见[当前支持范围](../availability.md#项目协作)。
