# 当前支持范围

本页区分“工作台已实现”“需要配置／授权”和“尚待真实环境验收”。它不是所有外部服务已经上线的承诺。内部开发的暂存事项仍由团队任务清单维护。

## 文件预览

| 来源 | 内嵌预览 | 超限或其它类型 |
| --- | --- | --- |
| 资料库文件／正式作品 | UTF-8 纯文本、Markdown、CSV；最多 65,536 字节 | 按可用权限下载，不承诺内嵌渲染 |
| Canvas 过程文件 | 上述文本及 JSON 的纯文本预览，同样受大小限制 | 按界面提供的下载操作处理 |

这不是 PDF／Office／图片全格式编辑器。附件能被上传，也不等于所有模型或读取工具都支持解析该格式；执行能力与预览能力是两回事。

## 语音输入

支持的浏览器可以通过语音按钮请求麦克风权限，把识别结果加入可编辑草稿。先检查并编辑文本，再主动发送；识别完成不自动发出消息。

浏览器兼容性、麦克风权限及识别服务可用性会影响结果。当前方式使用浏览器原生语音识别，不是上传一份录音到 Kokoro 的通用转写接口。真实非空转写进入草稿已有验证；本人编辑后发送的最终体验验收暂存下一轮，不据此宣传全浏览器已验证。

## 外部聊天连接

Task A 提供的 Telegram、LINE、Slack 设置入口位于 `/app/agents`。按实际向导完成设置和必要授权，核对连接状态；需要停用时使用正式断开操作。

- 服务端配置和你的外部账号授权是前提，卡片存在不代表已经连接。
- 本地协议及浏览器流程已验；真实外部账号授权、收发、撤销仍待各供应商环境验收。
- **设置 → 集成** 中的说明卡片不等于上述可用入口；禁用按钮不要当作已完成连接的证明。
- Skills、MCP、自定义 API、账户与团队管理有独立的产品边界，不以 Task A 收尾改变其交付状态。

连接概念参考 [Manus Connectors](https://manus.im/docs/integrations/connectors)，核对于 2026-11-11 UTC；没有照搬其目录、连接数量或能力承诺。

## 执行环境

过程文件能力取决于实际选择、配置和授权的后端。已验证路径包括 State、受支持的本地／Docker 路径，以及锁定 E2B SDK 对官方 envd Docker 的真实进程与文件协议。

本地 envd 协议验证不等于 E2B 云控制面的创建、重连和回收验收。也不意味着浏览器用户可以不经配置访问宿主机文件或任意执行环境。

## 分享与购买

已有公开会话快照是只读的；它不是继续聊天或操作原任务的入口。分享创建、权限管理和团队访问以对应正式功能为准，不从一个公开链接推断全部访问权。

当前购买／checkout 保持关闭，真实支付不在本次交付中。可见套餐信息不是付款已接通的证明。
