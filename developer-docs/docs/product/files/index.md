# 文件与结果

## 选择这次需要的资料

在输入框打开 **＋**，按来源选择：

| 来源 | 操作 | 结果 |
| --- | --- | --- |
| 本地文件 | 选择文件并等待上传状态确认 | 文件成为本次消息的候选资料 |
| 资料库 | 选择当前可访问的文件 | 引用已有资料，不要求再次上传 |
| 最近任务 | 选择历史交付文件或可引用的最终答复 | 把正式结果作为新任务的输入 |

一次消息最多选择 16 项。选择或移除不会自动发送；取消选择也不等于删除原文件。项目内的可选资料受当前项目范围约束。

历史答案引用使用已完成的正式最终答复，不是任意过程文本、隐藏推理或一份自动拼接的全历史摘要。先前任务没有交付文件，不代表它的最终答复一定不可引用；以选择器实际提供的选项为准。

## 查看交付文件与过程文件

从回复的交付卡片或过程文件入口打开文件面板。在 Files 中选文件，在 Preview 中查看内容；需要时下载、全屏或关闭后重开。

- **交付文件**是 Agent 已正式交付的结果。
- **过程文件**是支持的执行环境中已发布的过程输出版本，不保证每个工具、路径和任意文件都会出现。
- 同一路径可能对应不同执行或多个不可变版本；选中哪个版本，就读取那个版本的字节，不自动改为最新磁盘文件。
- 文件面板以只读预览和下载为主，不是任意沙箱文件浏览器或在线编辑器。格式和大小限制见下方的[文件预览](#文件预览)。

## 执行文件与正式交付

支持的沙箱可以运行脚本并生成工作区文件；生成文件不等于已经正式交付。以回复中的交付卡片确认结果，需要时下载核对。执行环境可按部署配置替换，不要求每个普通任务先连接自定义 API。

如果任务在生成文件后失败，保留原失败事实；可以在原会话明确要求继续交付已有文件，是否仍可用由实际执行环境和权限确认，不保证所有失败都会保留文件，也不自动重新运行脚本。

## 在资料库管理文件

打开 `/app/library`，使用当前列表的搜索、分页、上传和下载。作品可以收藏、查看仅收藏列表；有已确认来源时可返回原任务。

删除文件与从输入框移除引用不同。删除前确认影响；收藏也不会扩大你对来源任务或文件的权限。来源已经失效时，不根据文件名猜测另一个任务地址。

## 文件预览

| 来源 | 内嵌预览 | 超限或其它类型 |
| --- | --- | --- |
| 资料库文件／正式作品 | UTF-8 纯文本、Markdown、CSV；最多 65,536 字节 | 按可用权限下载，不承诺内嵌渲染 |
| Canvas 过程文件 | 上述文本及 JSON 的纯文本预览，同样受大小限制 | 按界面提供的下载操作处理 |

这不是 PDF／Office／图片全格式编辑器。附件能被上传，也不等于所有模型或读取工具都支持解析该格式；执行能力与预览能力是两回事。
